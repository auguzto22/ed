# Recly-BR-Informal categories

These folders are reserved for consented, verified hard examples. Automatic
captions are never imported as ground truth. Each future example must retain
the original audio, a human-verified transcript, timing metadata, provenance
and license information.

Planned categories: `ptbr_slang`, `english_words`, `social_media`,
`technology`, `gaming`, `proper_names`, `brands`, `mixed_language` and
`hard_examples`.
